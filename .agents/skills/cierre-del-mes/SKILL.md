# Cierre del mes

1. Pedime la lista de clientes activos si no la tenés.
2. Para cada cliente, armá qué documentos faltan: facturas, extractos, recibos.
3. Redactá un recordatorio amable para cada uno, de 3 frases, en borrador.
4. Al final, una tabla: cliente, qué falta, fecha del recordatorio. Guardala en `trabajos/cierre-[mes].md`.

Reglas: no envíes nada. Si un dato falta, marcalo [pendiente].
