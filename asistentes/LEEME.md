# 20 asistentes listos para usar

Cada archivo es un asistente completo, con las 5 partes: PERSONA, TAREA, CONTEXTO, FORMATO y REGLAS.

1. Abrí el que te sirve y cambiá los [corchetes].
2. Copiá las instrucciones en un Proyecto o una Habilidad, o pedíselo a tu cerebro: «Usá asistentes/01-correos-y-mensajes.md para responder esto».
3. Dale el archivo sugerido. Con uno alcanza para empezar.
4. Probalo con la pregunta de prueba. Si algo no te convence, ajustá una regla.
