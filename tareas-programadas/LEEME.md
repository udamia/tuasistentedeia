# Tareas programadas: plantillas

La fórmula de una buena tarea: **cuándo + qué querés + para quién + en qué formato + dónde te lo deja.**

## Dónde se programa cada una

| App | Cómo | ¿Sigue con la compu apagada? |
|---|---|---|
| Claude (app, cualquier plan pago) | En un chat: «De lunes a viernes a las 7:30, hacé esto: …» y **Programar**. O **Programadas > Nueva tarea > Configurar manualmente** | Sí, corre en la nube (salvo que elijas una carpeta de tu compu) |
| Claude Code, en la nube | `/schedule` en la terminal o claude.ai/code/routines > New task | Sí |
| Claude Code, en tu computadora | Pestaña Code > **Scheduled > New task > Set up manually** > Advanced settings > **Only on this computer** | No: la app abierta y la compu despierta |
| ChatGPT | Un chat nuevo con el horario escrito en la orden. Se ven en **Programadas** | Sí |
| ChatGPT, cuando llega un correo (desde Plus) | **Work**, con Gmail conectado: revisá activador, condición y pedido | Sí |
| Gemini | Pedido con día y hora (programaciones) o **Tarea** debajo del cuadro | Sí, salvo que Tarea use el Chrome de tu compu |
| Grok | grok.com/automations | Sí |
